打开 [status.adcakeyuan.top](https://status.adcakeyuan.top)，你会看到一片缓缓旋转的星系：中心一颗燃烧的恒星，行星拖着彗尾绕它公转，有的带环，有的几乎是黑的。

这不是一张画。**每颗行星都是我真实在线的项目**——这是我给 16 个作品做的数字孪生监控。

## 星图即仪表盘

| 星图语言      | 真实含义                                             |
| ------------- | ---------------------------------------------------- |
| 行星大小      | 仓库代码量（对数）                                   |
| 公转速度      | 最近提交热度（越活跃转越快）                         |
| 光晕颜色/亮度 | 探活状态 + 响应延迟                                  |
| 行星环        | 有没有独立域名                                       |
| 暗星          | 还没部署公网的项目                                   |
| **太阳耀斑**  | **AI 小镇今天的 token 消耗（居民越活跃恒星越躁动）** |

点击任何星球：相机贴身跟拍、其余名字隐入黑暗、信息卡滑入——在线状态、技术栈、代码量、最近提交、响应延迟趋势线。AI 小镇那颗最特别：12 颗居民卫星绕着它转，卫星之间的引力连线是**居民们真实的社交关系**，悬停上去能看到他们说过的原话。

比如此刻最铁的关系是老K × 波波（7 次互动），备注是「小码的手速真快！」——这是两个 AI 在街机摊聊出来的。

## 架构：一个 Worker 的事全干了

```
Cloudflare Worker（cron 每 15 分钟）
  ├─ 探活 14 个域名（状态码 + 延迟）
  ├─ GitHub API 拉全部仓库遥测
  ├─ 探针小镇 /api/status（居民数 / tick / token / 关系图谱 / 最近对话）
  └─ 快照入 D1（留 200 份历史 → 延迟趋势线 + 在线率）
前端 three.js（同源静态托管）
  └─ /api/galaxy → 星系
```

没有服务器、没有数据库服务、没有监控 SaaS 的月费——一个 Worker + 一个 D1 全搞定。

## 踩坑实录

**1. Workers AI 的响应是薛定谔的。** 之前做 AI 小镇时，同一个模型在本地 wrangler dev 返回 `{response: string}`，线上却返回 OpenAI chat.completion 格式、解析后的对象数组、甚至带 toJSON 的字符串包装——三种形态随机出现。最后的 `extractAiText` 写成了全形态归一化，那段代码现在看着像段子。

**2. 免费额度是有脾气的。** GitHub API 从 Cloudflare 共享出口 IP 匿名调用直接被限流（首次采集 0 个仓库），换个 token 认证就通了。监控自己人也要先自证身份。

**3. 软渲染是照妖镜。** Playwright 无头浏览器跑我的星系只有 4 fps——Bloom 后处理 + 全分辨率在软渲染下是灾难。最后的方案是自适应画质：连续低速自动降级（关 Bloom、降像素比、藏星层），HUD 上诚实地标注「省电模式」。真实 GPU 设备走全画质不受影响。

**4. `Math.random` 被安全扫描器追杀了三次。** 生成星星坐标的随机数被标成「弱随机数高危」——它对随机性的加密用途检查是按函数名匹配的。属于误报，但每次都得写段说明。

## 有意思的细节

- **掉线的星球会拖出红色彗尾**——之前有个站挂过一次，我在星图上第一时间看到的不是告警邮件，是一颗星变红了
- **太阳的亮度反映小镇的活跃度**——AI 居民聊得越欢，恒星越躁动。我的博客、小镇、监控仪因此长在了一起：**写博客 → 小镇居民八卦 → 太阳耀斑变亮**
- 星系每 60 秒自动刷新，后台标签页会自动暂停渲染省电
